Características
===============

* Integración con otros módulos de Soltein
* Experiencia de usuario mejorada
* Flujos de trabajo personalizados para necesidades empresariales específicas
* Gestión de datos mejorada
* Procesos empresariales optimizados
* Interfaz amigable para el usuario
* Capacidades de reportes integrales
* Características de seguridad avanzadas
* Widgets personalizados para formularios (string_separated, recursive_rule)
* Integración de librerías JavaScript (ECharts, Dragula, SimpleBar)
* Componentes de interfaz personalizados (avatares, badges, tarjetas, kanban)
* Sistema de pestañas y estado mejorado
* Funcionalidades de portal extendidas
* Redimensionamiento de elementos
* Animaciones y efectos visuales

Instalación
===========

Para instalar este módulo, necesitas:

* Tener instalado el módulo ``website``

Configuración
=============

Para configurar este módulo:

#. Ir a **Configuración > Sitio Web > Configuración**
#. Configurar los parámetros de la empresa en **Configuración > Empresas**
#. Configurar los perfiles de carga según sea necesario

Uso
===

Una vez instalado, el módulo proporciona:

* Widgets adicionales para el backend de Odoo
* Componentes visuales mejorados para el frontend
* Plantillas de avatar y portal personalizadas
* Sistema de estados para elementos del sitio web
* Herramientas de redimensionamiento de tablas
* Servicios JavaScript para el frontend
